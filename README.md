# ANSI C Learning

A personal learning repository based on **The C Programming Language (Second Edition)** by Brian W. Kernighan and Dennis M. Ritchie.

## About

This repository documents my journey of learning and exploring ANSI C through code examples, exercises, and personal experiments.

I already have experience with C++ and the fundamentals of C. My goal is to strengthen my understanding of C, explore its lower-level concepts, and build a solid foundation in systems programming.

## Goals

- Review and reinforce the fundamentals of C.
- Understand pointers and memory management.
- Learn about arrays, strings, and structures.
- Explore function pointers and other advanced concepts.
- Practice by implementing examples and solving exercises.
- Improve my technical English while studying the book.
